Safari turned off the umbilical extension after this update. To turn it back on, open Safari Settings, choose Extensions, and tick umbilical.

The main window no longer opens a second blank window on launch. Pause and resume hide on completed, failed, and cancelled downloads.

Confirmed metalink files start the files they name after every mirror URL and output name is checked. Torrents no longer save extra torrent copies in the download folder. Removing an unfinished download deletes that download's partial file and matching .aria2 control file. Video downloads require a version with sound and fail plainly when none exists. Video files are named after the title and stay inside the download folder. A YouTube or other video-site handoff uses the video download path. Removing a download cannot clear a different row if the list changed while waiting.
