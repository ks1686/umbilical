Safari turned off the umbilical extension after this update. To turn it back on, open Safari Settings, choose Extensions, and tick umbilical. The notice shows when the extension is off until it is dismissed for this version.

Opening the Safari toolbar popup no longer turns download interception off. The Safari extension version matches the app version.

The main window no longer opens a second blank window on launch. Pause and resume hide on completed, failed, and cancelled downloads.

Confirmed metalink files start the files they name after every mirror URL and output name is checked. Torrents no longer save extra torrent copies in the download folder. Removing an unfinished download deletes that download's partial file and matching .aria2 control file after aria2 has finished the remove. A finished file that already used the requested name is left in place. Video sites work when they offer a single file with sound. Some sites, including YouTube, may show a clear error instead. Video files are named after the title and stay inside the download folder. A video-site handoff uses the video download path. Removing a download cannot clear a different row if the list changed while waiting. An update no longer restores leftover windows from an older multi-window build. Rejection alerts appear once for the app, not once in every window. A second confirm request waits its turn instead of replacing the first. One confirm starts only that download. At most ten wait behind the open sheet.
