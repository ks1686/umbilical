# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/ks1686/umbilical/security/advisories/new).
Do not open a public issue for a security problem.

Include what you found, steps to reproduce, and the version or commit you tested.
You can expect an initial reply within 7 days.

## Supported versions

Only the latest release receives security fixes.
