umbilical

Right-click a link and choose Download with umbilical. Safari hides that item until website access is allowed. Right-click a page or link for Download video with umbilical.

Click Allow website access below. Safari will ask. You can also allow it in Safari Settings > Extensions > umbilical.

The extension sends the clicked link's URL and, when the path has one, a file name. It does not read the page, form fields, cookies, or other headers.

If a download needs the site's login session, it can fail in umbilical. Use Safari's own download in that case.

Intercept download links

Off by default. Safari has no downloads API, so interception watches clicks instead. Turning this on asks Safari for access to all websites so the script can see a click on whatever page you are on.

After you allow that, the script still reads only the clicked link's address, download name, and type. It does not read the rest of the page. Option-click a link to skip interception and use Safari as usual. You can turn interception off at any time. Website access stays so the link menu still works; remove it in Safari Settings if you want.
