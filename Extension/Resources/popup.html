umbilical

Right-click a link and choose Download with umbilical. Safari hides that item until website access is allowed.

Click Allow website access below. Safari will ask. You can also allow it in Safari Settings > Extensions > umbilical.

The extension sends the clicked link's URL and, when the path has one, a file name. It does not read the page, form fields, cookies, or other headers.

If a download needs the site's login session, it can fail in umbilical. Use Safari's own download in that case.
